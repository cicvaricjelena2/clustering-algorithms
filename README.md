# Clustering algorithms: C-Means and Maximum Likelihood Estimation

Project Overview

This project explores unsupervised learning and statistical clustering techniques through the implementation of C-Means clustering and Maximum Likelihood Estimation (MLE)-based classification.

The main objective is to investigate how different initialization strategies, cluster assignments, and assumptions about the number of clusters affect the performance of clustering algorithms.

Experiments are conducted using synthetic two-dimensional datasets with both linearly and non-linearly separable structures.

Part 1: C-Means Clustering

The first part focuses on implementing C-Means clustering and investigating how initialization strategies influence clustering results.

1. Synthetic Data Generation

Four two-dimensional Gaussian classes are generated, each containing 500 samples.

Each class is defined by:

* A mean vector.
* A covariance matrix.
* A Gaussian probability distribution.

The generated samples are visualized to examine their spatial distributions.

2. Fully Stochastic Initialization

An initial clustering is generated by randomly assigning observations to four clusters.

The algorithm iteratively performs:

* Calculation of cluster centroids.
* Computation of Euclidean distances.
* Reassignment of observations to the nearest centroid.
* Updating of cluster memberships.

The process continues until no further reclassification occurs or the maximum number of iterations is reached.

The average number of iterations is also investigated through repeated experiments.

3. Partially Stochastic Initialization

A partially stochastic initialization strategy is implemented to investigate whether providing partial prior information improves convergence.

In this approach, a subset of observations is assigned to its corresponding initial cluster, while the remaining observations are randomly distributed.

The resulting clustering process and average number of iterations are compared with fully stochastic initialization.

4. Unknown Number of Clusters

The algorithm is further investigated under different assumptions about the number of clusters.

Experiments are conducted by assuming three and five clusters, even though the generated dataset contains four original Gaussian classes.

This demonstrates how the assumed number of clusters affects the final partitioning of the data.

Part 2: Maximum Likelihood Estimation (MLE)

The second part investigates a probabilistic clustering approach based on Gaussian probability density functions and iterative parameter estimation.

1. Gaussian Parameter Estimation

For each cluster, the following parameters are estimated:

* Mean vector.
* Covariance matrix.
* Prior probability of cluster membership.

Multivariate Gaussian probability density functions are calculated using the estimated parameters.

2. Probabilistic Cluster Assignment

Cluster membership probabilities are calculated using Bayesian posterior probabilities.

Each observation is assigned probabilistically to the clusters based on the estimated Gaussian distributions and prior probabilities.

3. Iterative Parameter Estimation

The Gaussian parameters and cluster membership probabilities are iteratively updated.

The process includes:

* Estimation of posterior membership probabilities.
* Updating of cluster means.
* Updating of covariance matrices.
* Updating of prior probabilities.
* Recalculation of cluster assignments.

The algorithm continues until convergence or the maximum iteration limit is reached.

4. Different Initialization Strategies

The probabilistic clustering approach is investigated using different initialization strategies:

* Fully stochastic initialization.
* Partially stochastic initialization.
* Different assumed numbers of clusters.

The average number of iterations is examined across repeated experiments.

Part 3: Nonlinearly Separable Data

The final part investigates clustering performance on a dataset containing two nonlinearly separable classes.

1. Synthetic Dataset Generation

Two circular structures are generated:

* An inner circular region.
* An outer circular ring.

The dataset contains 500 observations in each class.

This configuration creates a nonlinearly separable classification problem.

2. Fully Stochastic Initialization

Observations are randomly assigned to two initial clusters.

The algorithm estimates Gaussian parameters and iteratively updates cluster memberships based on probabilistic discriminant functions.

3. Partially Stochastic Initialization

A partially stochastic initialization is also investigated.

A subset of observations is retained in its original cluster, while the remaining observations are randomly assigned.

The resulting clustering behavior and convergence are examined.

4. Different Number of Clusters

An additional experiment assumes three clusters for data originally generated from two circular classes.

This allows the investigation of how the assumed number of clusters affects the resulting partitioning.

Key Takeaways

This project demonstrates the implementation and analysis of iterative clustering algorithms using synthetic Gaussian and nonlinearly separable datasets.

It explores the importance of initialization strategies, Gaussian parameter estimation, probabilistic cluster assignments, and assumptions about the number of clusters.

The experiments provide practical insight into the behavior of distance-based and probabilistic clustering approaches.
